# 本题知识图谱

## 已交付

“轮到你了”增加入口，打开独立全屏图谱视图。学习会话仅作为只读输入，不改变 activeGate、掌握状态、答案或聊天记录。节点可拖动，空白区域可平移，触摸双指缩放；节点点击与拖拽设有阈值。初始展开根节点的直接关系，后续按节点展开基础知识。共享基础只出现一次。选中知识点突出关联边，移动视野避开底部知识卡片。支持键盘打开和移动节点，以及减少动态效果偏好。

关系沿核心向依赖展开，箭头与“需要先理解 / 结合使用”标签解释方向。卡片包含概念、在本题的作用、题目原文依据和关系理由。整理布局不改变连线。图谱及布局按 requestId 和完整题目身份保存在本机；旧缓存、损坏坐标与不合法展开记录安全降级。返回对话恢复原滚动与任务，生成中关闭会取消请求。

## 数据边界

新增只读 POST /learning/knowledge-map，沿用签名会话、同源检查、限流和模型配置。45 秒请求上限。模型选择编号式原题证据，由程序回填原文，不允许把模型改写后的公式伪装成原题引用。结果检查节点唯一性、边端点、根、连通性、循环、层数和大小上限。校验失败显示重试；不生成通用假图谱代替。

知识选择及语义关联仍由 AI 生成，结构与引用校验不等于学科知识已经完整证明，也不承诺覆盖任意题目。页面保留简短 AI 提示，不展示开发核验日志。

## 代码位置

- components/problem-knowledge-map.tsx / .module.css：按需加载的画布和全屏知识卡片，基于 React Flow。

- lib/learning/providers/knowledge-map.ts：知识映射提示和引用编号解析。
- lib/learning/http/knowledge-map.ts：独立只读接口。
- components/learning-chat.tsx、education-chat-app.tsx：入口与当前签名会话传递。

## 2026-09-06 交互修复与按需详情

- 用户现场确认：节点 DOM 仍存在但全部 visibility:hidden。受控节点重建时丢弃 measured，导致组件隐藏节点且无法可靠 fitView。
- 保存 dimensions 变更，拖拽、选中和整理不再清空测量尺寸；“整理”和“查看全图”以当前坐标、节点尺寸和画布大小直接恢复视野，不等待内部布局同步。
- 首次请求只生成节点、证据和关系（overviewOnly），不提前生成所有说明。选中节点后，同一只读接口接收 map/nodeId，核验图谱、原题依据与节点存在性后按需生成详情；不改变学习进度。失败可重试，不阻断画布，切换节点/退出会取消旧请求。
- 详情缓存按本题请求、节点和完整图谱内容隔离；旧版本完整图谱缓存继续可用。
- 扩展 UI 回归：5 轮拖动/展开收起后所有节点可见，移出屏幕后两个恢复按钮分别单独找回；首屏不请求详情、详情错误重试、重开复用缓存。838 项测试通过。
- 本轮两道真实样题首图耗时：物理 9.23 秒，化学 10.14 秒；点击后详情分别 4.81 秒、8.82 秒。仅为样本，不承诺固定响应时间或学科解释完全正确。
