# 首页改为固定解题欢迎语

## Intent

**Problem:** 随机名言、出处与换一句按钮让用户难以理解首页用途。

**Approach:** 固定欢迎语分为两行：小号绿色“Hey，”搭配醒目的“来一起解题吧”，统一使用无衬线字体。欢迎语与输入框组成居中的紧凑区域，移除圆环、点阵与上方引言标签；增加拍照或输入题目的简短提示。浅暖底色搭配轻微绿色渐变，弱化输入框阴影。讲解等待期间的寄语与解题功能不变。未提交代码。

## Verification

- 类型检查、lint、diff 空白检查通过。
- 浏览器检查 1280×720、390×844、320×568：标题与输入框完整可见，无重叠。
- 独立静态审查未发现本轮首页布局回归。
- 未验证真实手机软键盘；仅调整首页，不改变会话中的底部输入框。
