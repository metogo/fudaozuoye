## Intent

把当前原题演示接入确定性的数量关系模型。第一期仅覆盖明确可解析的小学数学：长方形面积/周长/单边增长，等份乘除，匀速行程，同单位比较/合计，整体分数取量。允许模型编排完整步骤的分组，不允许模型修改数值、坐标或数学运算。复杂与未覆盖题型明确提示，不能使用通用图形伪装成成功。

## Implementation

- math.js 15.2.0：精确分数运算、长度单位换算，兼容当前 Node 20 云函数；代替要求 Node 22 的最新 Cortex Compute Engine，避免升级部署环境。
- 服务端 `teaching-compiler.ts`：受限题型匹配，检查输入数量、适用条件和已解答案；输出完整教学步骤及同一数学模型的图元。全部数值与运算由程序生成。
- `TeachingScene`：受限矩形、线段和文本协议；图元尺寸取自同一份数量数据，无模型代码或任意 SVG。
- JSXGraph：按相同数学坐标渲染；加载失败时显示同一协议生成的 SVG。原区域、宽度、比例、等份数跨步骤保持一致。
- 模型规划预算 5 秒：仅可合并相邻步骤，完整覆盖不得遗漏重复；失败采用完整模板步骤。该预算不包括首次准备原题完整解答。
- 同题缓存保留、编译器版本纳入指纹；完整生成后才签发凭证，关闭后才转入回忆。
- 云函数包独立声明并锁定 math.js 依赖，部署时启用依赖安装。

## Acceptance

- 黄金样例覆盖六种模板；核对尺寸比例、等份数、分数选取、结果及单位。
- 未覆盖、额外数值、复杂条件、错误答案、缺单位、取消均不能静默成功。
- 实际浏览器验证六类已解题会话：真实 HTTP 和当前配置模型规划、逐帧 JSXGraph 渲染、关闭/重开不重复生成。截图和结果保存在 `outputs/illustration-e2e/`，不包含凭证或密钥。
- 识题与完整求解不属于此隔离验收的测量范围；本阶段不宣称覆盖所有小学题，更不宣称覆盖全部数理化。

## Review order

1. `lib/learning/providers/teaching-compiler.ts`：题型前提、输入完整性、运算和答案核对。
2. `lib/learning/teaching-scene.ts`、`components/teaching-scene.tsx`：同源数据和渲染一致性。
3. `lib/learning/providers/adapter.ts`：模型权限、预算、取消和完整事件。
4. `tests/illustration-demo.test.ts`、`scripts/illustration-e2e.mjs`：跨题型质量与真实浏览器证据。

## Verification

- 33 个测试文件 / 575 项测试通过；TypeScript 与 ESLint 通过。
- Next.js 生产构建与云函数构建通过。
- 六类已解题会话在真实模型与浏览器下通过：长方形 2121ms、等份乘法 3225ms、平均分 1704ms、匀速行程 1702ms、比较 2207ms、分数取量 2203ms；每题重开约 400ms，生成请求计数仍为 1。手机宽度逐帧截图已人工查看菜园、行程和分数关键帧。
- 新题输入（无注入会话）也通过：菜园题生成 3 帧、行程题 2 帧。点击演示到完成分别 9905ms / 7978ms，包含尚未完成的标准解答准备，不等同纯演示规划耗时。关闭重开均复用。
- 独立临时目录 `npm ci --omit=dev` 后成功加载云函数入口，math.js 精确分数校验通过；部署包同时补齐原有 KaTeX 运行时依赖。
- 实际覆盖仍受受限句式和单位约束；这些样例证明已覆盖路径可用，不代表任意小学题都能生成演示。
