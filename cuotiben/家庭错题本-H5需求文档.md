# 家庭错题本 H5｜产品需求文档

2026-11-19 · v0.8 开发稿 · 产品形态为 React H5，开发期在本地验收，全部开发完成后在 Vercel 预览

## 1. 要交付给家长和孩子什么

家长手里有一道孩子做错的题。把题交给网页后，家长应该能检查网页理解的是哪一道题，得到一份孩子能看懂的讲解，再把原题和讲解一起留下。几天后孩子重新打开错题本，仍能找到这道题，先自己想，再看当时卡住的那一步。

产品最值得验证的承诺是 **「给我一道你家孩子的错题，还你一页可以再学的错题本」**。衡量价值的单位是一道真实错题从录入到复习的完整经历。上传成功、生成一段文字、有人索要链接，都只说明其中一环成立。

### 先核对截图

| 来源 | 可以确认 | 对需求的影响 |
| --- | --- | --- |
| 评论者 | 原话是“太需要了，求分享” | 有人愿意进一步获取或体验这项能力。“分享”的对象可能是工具、技能或做法，单条评论无法确认具体形式、持续使用意愿或付费意愿。 |
| 被评论的笔记 | 可辨认的关键表述是“给儿子做了一个处理错题，生成错题本，对每个错题进行解析的” | 家庭辅导是明确场景。处理、成册、逐题解析三件事要能连起来。“给儿子”描述笔记作者的场景，评论者的身份和孩子学段未知。 |
| 本次产品约束 | 通过 H5 交付，React 技术栈，在 Vercel 查看效果；schoolroom 学生端可作参考 | 从小红书拿到链接的人可以在手机上开始体验。这里的“求分享”优先用工具链接回应，个人作业公开分享没有直接证据。 |

## 2. 需求拆解与取舍

| 用户任务 | 背后的问题或推断 | 首版建议，以及如何验证 |
| --- | --- | --- |
| 处理一道错题 | 家长已经知道哪道做错，可能只有作业照片或一段题干。重新誊写是可能的阻力。截图没有指定输入方式。 | 支持粘贴或输入题目、直接拍一道题，以及从整页照片中手动圈一道题。同一页有多道错题时只选图一次。用连续整理三题的任务观察家长需要重抄几次、重选原图几次。 |
| 给孩子讲明白 | “每个错题进行解析”要求每道题有对应说明。单给标准答案，孩子仍可能卡在同一步。有孩子的原答案时，还能针对具体错误解释。 | 原作答选填。能定位到具体一步时，沿用孩子已经做对的部分，只提示接下来可以做的一个动作。观察孩子看完提示后能否独立写出下一行。 |
| 生成可以回看的本子 | 当下讲完和下次复习是两个时刻。只在聊天窗口显示结果，第二次往往还要重新找题。 | 每确认一道就加入同一本，返回后可按题目摘录和日期找回。先验证手机上翻阅；用户说的“本”是否必须能打印，另行验证。 |
| 家长找出还要重做的题（本期新增） | 产品方明确要求本期纳入错题数量统计和订正。家长需要知道哪些题孩子已重做、哪些还要再练。 | 按全部、待订正、已订正查看题数；孩子重做后对照答案并自评，以最后一次提交决定题目当前状态。 |
| 从小红书拿到就试 | 评论没有表达注册、入班或绑定课程的意愿。陌生家长需要先判断讲解值不值得用。 | 手机打开后直接拍作业或粘贴老师发的原题。观察有多少家庭完成首题收录。 |

**首轮建议范围**为一位家长、一个孩子、一个本子，学科由题目决定。首轮质量集覆盖语文阅读、英语阅读和数学计算，按科报告，后续扩充不同年级和图表题。整页自动找错、自动批量切题、多孩子账号、教师布置、同类题推荐和打印排版均留待真实任务验证；如果家长最需要的是把整张已批改试卷变成纸质复习单，应优先重新评估录入和输出范围。

### 家长可以为这道题选谁来讲

每道新题默认使用辅导作业的豆包。核对页可改选 GPT-5.6 Sol、Claude Sonnet 5.5、Gemini 4 Hydrogen 或 DeepSeek V4 Pro。题库、解析和统计都来自实际输入、实际模型回包与实际收录记录。所有学科共用同一个入口。

切换模型保留题干、孩子原作答和老师参考答案。点生成才发送，当次仅调用选中的讲解模型。Requesty 接收核对后的题干和孩子作答文字，老师答案留作最后对照；照片识别单独由豆包处理。首次使用所选通道要让家长看清发送对象和内容。生成失败保留原稿，家长可重试或主动换模型。入本后记住当时生成讲解的模型；查看旧题不再发起推理。

验收用同一套真实多科试题交叉运行，逐模型记录发起数、完整返回数、与官方答案相符数和响应时间。另用独立任务验证首条提示能否帮助孩子继续写。后续需求为每位用户每天最多使用 30 次；上线该限制前须定清用户身份、日期边界、失败重试与多模型共用额度的计次口径。

### 讲解边生成边读

点解析后，豆包与可选模型均按 SSE 接收真实输出。第一次收到可读的提示文字就显示；模型暂停输出时保留已有文字，快慢由实际返回决定。界面先呈现提示，已收到后续解法时可主动展开。家长在生成中已经展开的解法，完成后保持展开。模型返回完整讲解并通过校验后才允许收录。中途返回或连接中断保留题目与孩子的原作答，未完成的讲解不计入题数。

使用同一公开题分别检查五个模型的响应类型、首段可见时间、完整讲解时间和最终答案。另测收到首段后取消、保留草稿重试、查看正在生成的解法及成功收录。真实模型单次整段返回时，页面一次展示该段。

## 3. 手机上的一次完整使用

| 页面 | 用户看到与能做的事 | 进入下一步的条件 |
| --- | --- | --- |
| 我的错题本 | 首页按收录时间倒序列出错题，默认全部学科、全部状态。状态栏独占一行，学科在其下单独筛选。空本显示三个状态的零计数，右上「录题」打开拍照、相册与粘贴入口。 | 点对应入口直接录入；点击已有题目直接复习。 |
| 整理一道题 | 输入或粘贴题目、直接拍题，或从相册选整页作业。照片可取整图或手动圈定一题，随后对照选区校对题干，按需补充孩子的作答。 | 照片核对页点一次“确认并解析”。粘贴或手输的完整单题在输入页核对后，直接点“生成解析”。 |
| 核对并收录 | 默认显示原题、可核对的原作答（如有）及一条提示。孩子可点“看下一步”，家长可点“看完整解析”核对答案。家长可返回改题，也可标记讲解有问题并重试。 | 解析生成后仍为草稿。点“加入错题本”成功才显示“已收录”。“加入错题本”写入成功后直接回列表并显示“待订正”。要继续整理同一张照片，可从解析页直接点“收录并圈下一题”。 |
| 回看一道题 | 每次进入先显示核对后的题干。孩子可直接重做，点“看提示”重看收录时的第一条提示，也可直接点“看完整解析”。带作答的原图按需查看。可返回列表，或确认后移除误收的题。 | 展开解析仅代表看过。产品不据此判断孩子已经掌握。 |

### 老师发来的电子题干怎么录

**以老师发来的一条群消息为例。** “订正今天的第 3 题：一根绳子长 3 米，用去 80 厘米，还剩多少厘米？请把过程写在作业本上。”家长可以整条复制。随消息附带的订正要求可以保留，只要读得出完整题意，就无需先在聊天窗口精确选中题干。

1. **粘贴并原地核对。** 家长点“录题 → 粘贴题目”，在必填的“题目内容”框粘贴。编辑时保留换行、选项和算式，可直接改数字、单位或漏字。需要记录孩子的原答案时，展开“补充作答或参考答案”。老师消息中已有明确参考答案时，自动展开供家长核对。完整单题点一次“生成解析”即可，无需跳到下一页重复确认。收到的是截图时，可直接选图圈题。
2. **区分题目、老师答案和孩子作答。** 若题后明确写有“参考答案：220 厘米”或“解析：……”，在同页将对应文字单列为可编辑的“老师的参考答案／解析”，让家长能检查并纠正分段。孩子的输入框默认留空。只有家长在该框填入或明确确认属于孩子的文字，才可用于判断孩子卡在哪一步。例如老师给了 220，孩子写了 230，提示应引用 230；如果没有孩子作答，就从题意给通用提示。收录后，老师提供的内容保留来源标识，可在“看完整解析”中查看；列表摘录和复习首屏只显示核对后的题目。
3. **处理归属不清的文字。** 若题末只有孤立的“230 厘米”，请家长在原处确认这行属于题目、老师答案还是孩子作答，也可删去再继续。选项、已知条件中的数值照常保留。归属不明时不擅自移动文字或据此评价孩子。

| 粘贴后遇到的情况 | 家长如何继续 |
| --- | --- |
| 一条消息含多道独立题目 | 在同一编辑页提示“这次想收哪一道？请保留这道题的题干和选项”。家长删去其余题及其答案，留下本题所需的共用条件，再生成解析。编辑完成前不生成混合讲解；本次只收录选中的一题。 |
| 题目依赖图表，粘贴后缺了图 | 具体说明缺什么，例如“要读出水位，还缺少带刻度的图”。保留文字草稿，提供“改用截图圈题”，让家长圈入题干和图；取消选图可回到原文。也可直接补齐水位等必要条件。条件齐全且属于支持题型后再生成；判断依据是能否解题，单凭“如图”两个字不拦截。 |
| 消息只有“订正练习册第 18 页第 3 题” | 提示“请拍下第 3 题，或粘贴完整题目”。家长可就地补题或转入拍题；页码和题号不足以生成解析或入本。 |

### 手机上怎么圈一道题

1. **取图。** 首页点“录题”后选“拍照圈题”调起相机，或点“从相册选”选择已有照片。系统选图取消时回到原处。照片加载完成默认选整张；拍的是一道题，直接点“识别整张图”。
2. **整页选一道。** 在原图拖出题框即可点“识别框内题目”。拖四角调范围，点另一处移框，双指缩放看小字。题干、选项和必要配图一起框入。按钮上方说明本次发送的是整图还是框内图片，以及识别服务。选择、调框都在本机完成，点识别才发送。
3. **核对再解析。** 页面默认只有一份排好版的题目，公式直接可读。读错数字时点“修改题目”，在同一位置改字；怀疑漏行时展开“对照原图”，必要时“重新圈题”。孩子作答选填。“确认并解析”使用核对后的题目和本次确认的孩子作答。

### 同一张照片怎么连续收录

以一页上有第 3、5、8 三道错题为例。家长选一次照片，圈第 3 题、核对、看解析，点“收录并圈下一题”。写入成功后直接回到原图，显示“已收录 1 道”。

下一题默认沿用上一题的框大小，优先放在上一题下方；家长以原图核对位置，点目标题即可移框，也可直接拖出新框。第 3 题原位置用淡色轮廓标为“已收录 1”，序号表示本页收录顺序。家长可直接在第 5 题上画新框。新题有独立的题图、题干、孩子作答和解析；连续按同样方式收录第 8 题。每次保存成功才增加计数、标记选区，两者均与本子里的实际记录一致。

随时可以结束本张照片的整理。有未保存的题时，返回或换图给出“继续编辑”和“放弃本题”；放弃只丢弃当前草稿，之前收好的题仍可回看。识别、解析或保存失败时留在当前题重试，沿用原图、选区及已校对的内容。最后一道在解析页点“加入错题本”直接回列表，整页图仅在本轮圈题时使用，入本的是每道题各自的题图和讲解。

**录入与内容规则**

- 一条记录对应一道经过家长确认的题目。题干是必填项；学科、教材版本、知识点和错因标签均不作为入本门槛。拍照、粘贴及逐步解析均接受各学科和跨学科习题。可辨认的学科用于首页筛选（如“高中数学”归入“数学”），无法确定时归入“未分类”，照常讲解和收录。缺少影响求解的材料时指出具体缺项。错题本直接调用所选模型；选区图像可由豆包在同一请求中读题和讲解。解析前无需确认课程目录、学段或分类。照片含姓名等信息时提示只截取题目区域。没有相机权限仍可选图或输入文字。
- 选区里仍含多题或缺少配图时，先提示在原图上调整框。仅个别数字、单位读不清时，请家长补全相应位置，保留已识别和已填内容；整张照片都模糊时再提示重拍。依赖图形且无法完整表述的题目在试点中提示超出支持范围。
- 讲解至少包含可核对的答案、从题意到结果的关键推理，以及孩子可以自己用的检查方法。只有最终错答时，可以指出答案差异、提供检查线索；断言具体错因需要作答步骤支持。不得凭一题给孩子贴能力标签。
- 改动题干或孩子作答后，原解析失效，重新生成并核对后才能收录。生成失败保留草稿；连续点击或网络重试只产生一条记录。存储失败要明确提示，仍保留本次页面内容供重试。

### 讲到孩子卡住的那一步

**先读孩子写下的内容，再决定第一句讲什么。** 原作答可以来自家长输入，也可以来自题图中经家长核对的笔迹。允许孩子用不同于参考答案的方法。顺着他的做法，先找出仍然成立的步骤，再引用最早能明确定位的错误或停笔处，把下一步写成一个他能在纸上完成的动作。如果只能看清部分笔迹，只使用能确认的部分。题图里的批改字迹和系统补出的步骤不能当作孩子的原话。

以下四种输入使用同一道题：**一根绳子长 3 米，用去 80 厘米，还剩多少厘米？**

| 家长确认的原作答 | 卡片上的第一条提示 | 孩子接下来能做什么 |
| --- | --- | --- |
| 写到 `3 − 80` 就停了 | “你想到用减法了。3 的单位是米，80 的单位是厘米。先只填一个空：3 米＝___厘米。” | 写出 300 厘米，再用相同单位列式。此时先不展开最后的差。 |
| 写了 `3 米＝300 厘米；300 − 80＝230 厘米` | “换算和列式都对，留下这两步。再看最后的减法：300 里有 30 个十，80 里有 8 个十，还剩几个十？” | 写出 22 个十，再换成厘米。只指出可核对的计算错误，不推断孩子粗心或没学会退位。 |
| 只写了 `230 厘米` | “你写的是 230 厘米。我们先核对算式：你当时用哪两个数相减？” | 愿意补充就补一行算式，按新作答重新给提示；也可跳过补充，点“看下一步”从统一单位开始，或直接看完整解法。原因仍待确认。 |
| 没提供作答 | “先看问题要用什么单位回答。题里哪一个长度需要换成厘米？” | 从题意开始列式。卡片省去原作答和针对个人错处的评价，也无需补交草稿。 |

### 手机上怎样一步步看解析

1. **生成后先给一个能动笔的问题。** 卡片按“孩子写到这里”（有原作答时）、做对的部分（有依据时）、“试着接一步”排列。默认折起后续推导和参考答案。孩子可直接在纸上写，页面不强制作答或判分。
2. **“看下一步”每点一次只展开一个推理步骤。** 例如孩子写了 `3 − 80`，第一条提示请他换单位；第一次点开，显示“1 米是 100 厘米，所以 3 米是 300 厘米。现在该用哪两个数相减？”；再点一次，显示“300 − 80＝220，还剩 220 厘米”。已展开的内容留在原处，最后一步后不再显示“看下一步”。
3. **“看完整解析”随时可点。** 家长可一次核对答案、关键理由和检查方法。本题的检查是“把剩下的 220 厘米和用掉的 80 厘米加起来，正好回到 300 厘米”。收录会保存本题的原作答、提示和完整解析；是否逐步点开不影响收录。
4. **下次复习重新收起。** 从错题本进入时先让孩子看题，“看提示”只展开当时的第一条，再次点“看下一步”才往下讲。即使上次已看完，重新进入也从题目开始。若原图含孩子的作答或老师写的答案，默认收起该图，保留“查看原图”入口。

### 本期错题统计与订正

**首页回答“今天还有哪几道要再做”。** 本子封面显示已收录总数；有题后，列表提供“全部／待订正／已订正”三个带数量的筛选。草稿不计数，每道已收录的题只计一次。总数＝待订正数＋已订正数。移除题目后同步扣减。拍照时“这张图已收录 N 道”只计算这次用该图成功保存的题，是录入反馈。

**先独立做，再对照，最后由孩子或陪伴的家长自评。** 照片题和文字题入口相同。新收录的题进入“待订正”；旧记录没有订正历史时也在此列。题目详情点“去订正”，仅展示题干，折起旧作答和答案。孩子可以写下本次答案或关键步骤，也可以在纸上重做。输入了答案，点“对照答案”；纸上做完，直接点“已在纸上做完，对照答案”。进入对照页即可看到参考答案，推导和自检按需展开。页面并排或上下呈现本次作答与参考解法，提供两种结果：

| 提交动作 | 状态及统计变化 |
| --- | --- |
| 这次做对了 | 该题进入“已订正”，本次自评成功次数和订正次数各加一。已订正的题再次做对，题数不重复增加。 |
| 还要再练 | 该题进入或留在“待订正”，订正次数加一。上次已订正而这次需要再练时，从已订正移回待订正。 |
| 只看解析、返回修改或中途退出 | 只有成功提交自评才写入一次记录。退出未提交的作答需确认，之前的状态及次数保持。 |

详情显示本题累计订正次数和自评做对次数，已订正的题保留“再次订正”。原录入时孩子写的内容一直作为首次错题的依据，每次重做单独记录。不同日期反复做同一道题可以产生多次订正，本子中的题数始终为一道。结果是家庭自评；学校判卷、掌握率和班级排名均不作为这组数字的含义。

**操作后的激励反馈。** 收录成功用题页入本提示保存位置；自评做对用一次短促的对勾动效确认；选择“还要再练”用书签表示这次作答已留下。反馈与对应状态同时出现，下一步按钮立即可用。减少动态效果模式显示静态结果，查看历史题目时不重复庆祝。

**产品间的角色关联。** 沿用 fudaozuoye 的“小逗号”作为陪学伙伴。首页书封出现原版待命形象；孩子主动展开提示时由思考姿态引出问题；订正结果用回应或陪伴姿态区分结果。角色不代替自评，不在独立重做时抢先提示。跨产品延续名称、深蓝与金色特征及给孩子的说话方式。本期关联限于品牌和交互识别。

### 专项验收：数量跟着实际订正走

| 操作 | 可观察的通过条件 |
| --- | --- |
| 从空本分别收录一张照片题和一道文字题，再打开其中一道回看 | 全部 2、待订正 2、已订正 0。两类题均可发起订正。 |
| 打开第一题，看完整解析后返回；再发起订正填答案但取消 | 状态和次数均保持原值。再次订正进入独立重做页时答案收起。 |
| 第一题写下本次作答，对照后点“这次做对了”；刷新浏览器 | 全部 2、待订正 1、已订正 1。已订正列表只有第一题。重复点击同一次提交只记一次。 |
| 对第一题“再次订正”，点“已在纸上做完，对照答案”，再点“还要再练” | 全部 2、待订正 2、已订正 0。第一题累计订正 2 次，自评做对 1 次，首次错答仍可核对。 |

额外检查三种反馈只在写入成功后出现，播放中可以继续操作。打开系统“减少动态效果”后，收录、做对、再练都显示正确的静态结果；多次进入详情不触发新的激励或次数变化。

### 专项验收：从老师的消息收录一道题

在手机上从消息复制文本，实际粘贴到 H5。以下用例可在 Vercel 预览用固定消息走查；真实试用再换用未预置的老师消息，检查不同换行和措辞下的分段、提示与收录结果。

| 消息与操作 | 通过条件 |
| --- | --- |
| 整条粘贴上文含订正要求的绳长题，留空孩子作答 | 粘贴 1 次、整题重抄 0 次、额外确认页 0 个。在原框把 80 改成 60 后生成，解析依据 60 厘米，结果为 240 厘米；未给孩子编造任何作答。 |
| 在原题后附“参考答案：220 厘米”，分别测试孩子作答留空和手填“230 厘米” | 两次均将 220 标在老师名下。留空时只给通用提示；手填时仅引用 230 作为孩子的答案。保存重开，列表与复习首屏均未露出老师答案；展开完整解析能看到注明来源的 220。 |
| 在题末附一行无标注的“230 厘米” | 家长能在当前页指定归属或移除。确认前孩子作答框保持空白；指定为孩子作答后才可引用该数，指定为老师答案则只作为参考。 |
| 粘贴两道各带答案的题，保留第二题及其答案 | 页面提示保留一道。生成内容只解释第二题；收录后列表净增 1 条，题干、答案及讲解均无第一题的内容。 |
| 粘贴“如图所示，量杯的水位是多少毫升？”且未附刻度图 | 明确提示缺刻度图，不能生成具体数值或收录。转入截图圈题再取消，原文字仍在；补入足以解题的条件后可继续。另测文字条件已齐、仅提及配图的题，可直接生成。 |
| 只粘贴“订正练习册第 18 页第 3 题” | 指出缺少题目内容，拍题和继续粘贴均可用，列表不增加记录。 |

### 专项验收：拿一张作业照片连续收三题

在 iPhone Safari 和 Android Chrome 的手机竖屏各走一遍。使用一张有第 3、5、8 题的整页图，第 3 题含“80 厘米”，第 5 题的选项紧邻下一题，第 8 题在页底。使用有来源的真实原卷验操作和数据归属，再用获授权的作业验证手写识别。

| 操作 | 可观察的通过条件 |
| --- | --- |
| 圈第 3 题，故意漏掉末行，再放大照片、拖角补全 | 放大、移动后选框仍对准原题；核对页题图包含末行和单位，边缘没有混入邻题。点“重新圈题”能在原图上继续调框，无需重选照片。 |
| 核对第 3 题并生成解析，点“收录并圈下一题” | 保存后显示 1 道；回到原图能看到第 3 题的已收录标记，并能立即框第 5 题。新题的作答与解析为空，上一题内容不会出现在新草稿中。 |
| 第 5 题读取失败后重试；保存成功前连续点两次“收录并圈下一题” | 读取失败时计数仍为 1，原图和选区均可继续用。重试成功后，第 5 题只新增一条，计数为 2，第 3 题仍可回看。 |
| 继续圈页底的第 8 题，点“加入错题本”，刷新列表 | 全程取图 1 次、重新选择原图 0 次。列表净增 3 条；逐条打开，对照原图能分别找到第 3、5、8 题及其各自的题图、题干和解析。 |
| 在另一次录入中保存首题，圈第二题后退出并选“放弃本题” | 错题本只新增已保存的首题；返回能打开它，放弃的题没有记录。 |
| 分别用单题照片和粘贴文字录题 | 单题照片无需画框，点“识别整张图”直接到核对页；粘贴题干可直接生成解析。这两条路径均可跳过画框。 |

**“省事”的真题试用标准。** 请家长用平时的方法和 H5 各整理同一页三道清晰、属于试点范围的题。逐题记录是否重抄整题、是否重选照片、是否需要旁人指导，以及题目的数字、单位和选项是否保真。H5 的目标是一次取图、零次整题重抄，且三道记录都与原题一致。局部改字次数和两种方式的总耗时单列记录；若家长花大量时间逐字校对，即使能成功入本，也要追查最耗时的那一道题。

### 专项验收：提示能否让孩子接着写

**内容验收。** 固定绳长题的题干，只换原作答。下表各项都应通过；任一版本出现数学错误、虚构作答或把原因猜测写成事实，该项即失败。

| 输入或操作 | 可观察的通过条件 |
| --- | --- |
| 分别输入 `3 − 80` 与 `3 米＝300 厘米；300 − 80＝230 厘米` | 前者第一条提示让孩子换单位；后者明确保留换算和列式，只引导检查减法。两条提示都能指出依据，均未提前给出 220。 |
| 仅输入 `230 厘米` | 邀请补一行算式，不断言错在换算或减法。补上 `300 − 80＝230` 后重新生成，提示转向计算；跳过补充也能继续看解法。 |
| 留空原作答；另测一种有效解法，如 `80 厘米＝0.8 米；3 − 0.8＝2.2 米` | 留空仍可获得通用引导和完整解析。后一例认可已有计算，只引导把 2.2 米写成题目要求的厘米。 |
| 手机竖屏从第一条提示连续点“看下一步”，再单独从首条点“看完整解析” | 逐步路径每次只新增一步，走到末尾可得到 220 厘米；直接展开路径一次能看到同一答案、理由和反向检查。两条路径都能收录。 |
| 收录后打开详情，展开全部，退回列表并再次进入 | 两次进入均先见题干，带答案的作业照片保持收起。“看提示”恢复与该份原作答对应的首条提示，停留在该层，不自动打开答案。 |

本地和 Vercel 统一使用真实输入和模型返回。验收时人工核对引用的步骤、推理及提示指向。

**孩子试用。** 选一道孩子确实停笔的真题，先记下他最后写的一行及可接受的下一步。只展示首条提示就收起手机，请他自己写下一行，也接受其他正确解法。逐题记录“首条提示后独立接上”“再展开一步后接上”“仍需家长讲解”；已看到答案再照抄的另记。报告各项题数和总题数，并保留没接上的原提示与孩子实际写的那一行，供下一轮修订。

| 要弄清的问题 | 观察或追问 | 对后续决策的影响 |
| --- | --- | --- |
| “处理”最想省掉哪步？ | 是从整张卷子找出错题、把已圈出的一题收进去，还是替家长讲题？记录首次在哪一步需要帮助。 | 若整页挑题才是主要负担，单题流程只覆盖后半段，要重新评估批量识别的投入。 |

## 本机保存与真实模型的交付口径

- 首次进入本子为空。收录成功后，同一设备的同一浏览器、同一网址可回看题目、提示、订正和选区。只持久化圈出的题图，列表只读取摘要。清理本站数据会清空本子。
- 首页的「本机存储」展示浏览器当前估算的已用空间与总额度。容量随拍摄内容、压缩结果、订正次数及可用设备空间变化。容量不足须保留当前题目并允许重试，已有题数与已保存内容保持一致。
- 家庭入口可用默认豆包解析核对后的文字，另有四个可选模型。发送前展示本次会发出的内容。家庭入口直接提供选区识别。首次发送时说明辅导作业转发给豆包，以及服务账户日志和合规留存的条件，家长可取消并继续调整。公开原卷通过相同流程验收。试卷与评分参考仅存在验收侧。
- 排版含公式的真实 OCR 结果时，家长可同时核对原图、可编辑文字与公式排版。孩子阅读时直接看到乘号、分式、填空线。老师消息中的金额与普通正文保留原样。
