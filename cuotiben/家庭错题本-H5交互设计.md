# 小逗号 · 家庭错题本 H5 交互设计
配套《家庭错题本 H5 需求文档》v0.8。本稿用于手机交互评审与 React H5 实现。讲解来自家长选中的真实模型。

## 首页的两个使用时刻

首页直接展示本机错题。手机右上角保留一个「＋录题」入口，点开再选拍照、相册或粘贴。三个订正状态各占一栏，显示当前学科的题数。学科选择独占下一行，只列本子里已有的学科。空本省去学科栏。题干使用整行宽度，待订正题可直接重做。

学科采用本次真实解析给出的结果。未保存学科的旧题归「未分类」，家长可在详情改学科。学科和状态同时生效，交集为空时可一键回全部错题。

沿用 schoolroom 的按题收录、识别后确认、按订正状态找题。schoolroom 的题卡会按题源显示订正入口；家庭 H5 让拍照题和粘贴题共享同一条自评流程。家庭中的纸上重做也能留下订正记录。[学生端题卡](/Users/fanhua/schoolroom/apps/stu/app/err-book/_cmp/question-card.tsx:137) · [状态筛选](/Users/fanhua/schoolroom/apps/stu/app/err-book/_cmp/head/index.tsx:115)

## 页面与返回规则

| 页面 | 首要动作 | 返回、失败与恢复 |
| --- | --- | --- |
| 本子首页 | 默认展示错题，可组合筛选学科与订正状态，录题时再选来源。总数只计算已收录记录。 | 当前筛选无记录时显示对应空态，其余筛选仍能点击。 |
| 照片来源与圈题 | 拍照或相册。直接拍好的一题可以用整张；整页在图内拖框，四角调节，双指放大平移。 | 返回不会撤销已收录题。模糊、圈到多题或圈不全时，在原图重选；选框外压暗，已录位置标顺序。 |
| 题图核对／文字编辑 | 识别结果直接排版；修改时原位切换为编辑框，原图按需展开。孩子原作答选填，老师答案保留来源。 | OCR 或解析失败保留输入。缺图提供换图入口，取消选图保留文字。退出未收录的草稿时允许继续编辑。 |
| 解析草稿 | 首先露出孩子原作答和一条可动笔的提示。逐步展开或直达完整解析，随时收录。 | 返回修改后重算；未存成之前不显示“已收录”。 |
| 收录成功 | 在解析页点“加入错题本”直接回列表。照片题可点“收录并圈下一题”直接回原图。 | 同图继续时保留原图和标记，新题沿用框大小，清空上一题的作答和解析。 |
| 复习详情 | 首先只显示题干。重做用“去订正”，遇到困难可主动“看提示”。再次进入重置展开层级。 | 看提示、完整解析或原图均不改变订正状态。移除需确认并更新数量。 |
| 独立重做 → 对照答案 | 写本次作答或确认已在纸上重做，再看参考解法。对照页用“这次做对了／还要再练”提交。 | 对照页返回可改本次作答。未提交退出要确认；首次错答及先前订正结果始终保留。 |
| 订正结果 | 显示更新后的状态、累计订正次数、自评做对次数。可回本题，也可进入对应筛选。 | 同次重复提交只记一次。写入失败停在对照页，保留重试动作。 |

## 统计在什么时候变

家长录入 3 道，首页显示“全部 3、待订正 3、已订正 0”。孩子看过两题的提示，数字不动。第一题重做并自评做对后，数字变为 3／2／1。隔天再做第一题，选择“还要再练”，恢复为 3／3／0；该题仍保留两次重做记录。这使家长能区分“收了几道题”“重做过几次”和“这次还需不需要再练”。

## 让用户知道自己的每一步都被接住

收录成功时，直接告诉家长“刚收的题在待订正里”，同时保留从这张图继续选题的入口。重做分为“重做 1/2”和“对照 2/2”，孩子可以在看到答案前放心写。选“还要再练”后，明确告诉孩子这次作答已经记下，提供“回本题看提示”。还有其他待订正题时，可自愿“再做一道待订正”；没有其他题时，回到对应列表。上次还要练、这次自评做对，才出现“上次留下的这道题，这次你自己检查做对了”。

| 触发时刻 | 动效与时长 | 反馈含义 |
| --- | --- | --- |
| 一道题成功入本 | 小题页落入本子，约 500 毫秒 | 和“这张图已收录 N 道”同时出现，立即可选下一题。 |
| 自评做对并保存 | 绿色对勾写出，周围六道短笔触散开，约 650 毫秒 | 确认这一次的订正结果。仅当前操作播放一次。 |
| 选择还要再练并保存 | 小书签落在题页中，约 400 毫秒 | 表示下次能从待订正找回。这里保留平静的节奏，避免给孩子失败惩罚。 |

动效局限在结果卡的局部，无声音、无全屏遮罩，按钮即刻可点。失败、取消、重新打开详情均不会播放成功动效。系统开启“减少动态效果”时直接显示最终图形和文字。收录或自评成功后按需加载轻量 Lottie 播放器和对应动效。[schoolroom 订正反馈参考](/Users/fanhua/schoolroom/apps/stu/app/err-book/_cmp/correction-explosion.tsx)

## 小逗号在什么时候出现

沿用辅导作业产品已使用的三张透明角色原图，保留深蓝轮廓、金色眼睛和“小逗号”称呼。页首展示原版待命姿态，形成两个产品共同的识别点。提示卡用思考姿态带出“试着接一步”，正文直接问这道题的下一步。主动订正时把位置留给孩子写；提交自评后，做对用回应姿态配对勾，还要练用平静的待命姿态配书签。图形旁始终有结果文字，系统减少动态效果时角色仍可辨认。[原产品首页](/Users/fanhua/Documents/Codex/2026-08-25/wo-f/components/home-welcome-hero.tsx) · [原始角色素材说明](/Users/fanhua/Documents/Codex/2026-08-25/wo-f/public/brand/README.md)

## 手机上的操作细节

- 手机采用单列阅读。首页按题目状态导航，题干、原作答、讲解纵向排列。深绿色主按钮用于提交或前进，次按钮用于换路径，删除和放弃草稿用独立确认框。
- 页面内的返回和浏览器返回遵循同一套草稿保护。软键盘打开时允许随正文滚动到下一步按钮；按钮不悬浮遮住正在编辑的文字。平板沿用同一错题目录，题面居中，限制行长。核对、讲解、重做和对照在宽屏上并排展示原题与当前任务。手机按阅读顺序单列展示。
- 触控按钮最小高度 44 CSS 像素。缩放只占用图面手势，图面外正常滚动。状态同时使用文字和数值表达。
- 读取、生成、保存属于不同阶段。接真实服务时，进行中的按钮应显示当前动作并阻止重复提交；失败后在当前内容附近说明可恢复的动作。
- 正式版若要求跨设备或统计真实正确率，需追加账号、同步或判题需求。本版口径为当前浏览器、家庭自评。

## 评审走查

1. 从首页录入公开真题，生成后只看一条提示再返回，验证个人题数仍是原值。
2. 用“从相册选”整理第 3、5、8 题。检查每次入本与同图数量一致，三题可独立打开。
3. 粘贴真实授权的消息，分别用空作答、错误算式和仅有错答生成提示。收录后从详情进入订正，检查老师答案和原作答没有提前出现。
4. 对同一题先自评做对，再次订正选“还要再练”，刷新后核对状态、筛选数和次数。另测未提交退出及重复提交。
5. 真机试用关注能否一次圈准、是否知道判定结果来自自评，以及孩子看完首条提示能否接着写。桌面或模拟视口通过只说明交互可运行。


## 核对页的模型选择

模型选择器和解析按钮排在同一行。用系统选择器支持拇指和键盘操作，豆包是每道新题的初始值。选项变化不发请求。解析按钮旁写出发送内容、服务和模型，结果页和回看页显示“本题讲解 · 模型名”。在任一模型失败后留在编辑页，保留输入。没有开通 Requesty 的环境在选择器下方说明原因。


### 本机空间、发送确认与公式核对

首页的「本机存储」默认收起，点开才读取浏览器给出的空间估算。容量不足时，在当前动作旁显示原因，原题及已写的订正留在当前页面。回到同一网址可以继续查找已收录记录。

发题确认显示实际收件方和资料类别。用文字讲解时显示题干和孩子确认的原作答，启用识图时单独展示本题选区与图片处理说明。来源校验失败在原表单提示网页地址需核对。家长能继续编辑或重试。

识别后立即显示一份排好的题目。需要时点「修改题目」原位编辑或展开原图。整段粘贴含公式的单题同样直接排版。连续收录时保留原图和已录标记，预置与上一题同尺寸的框，可点题移框或拖选。仅在写入成功后更新计数。


### 全流程的扁平视觉与布局

白色题面、深墨色正文、细分隔线和绿色操作按钮贯穿各页。首页书本图标首次进入播放约 0.6 秒的翻页动画；返回首页保持静帧，减少动态效果时直接使用静帧。

| 页面 | 手机上的主任务 | 平板上的布局 |
| --- | --- | --- |
| 首页 | 先找错题和去订正，右上角可录题 | 同一套状态、学科筛选与题目列表 |
| 选图与圈题 | 拍摄或选择作业，拖动发亮的四角调整题目范围 | 左侧显示当前环节，右侧取景器保留大图和工具 |
| 核对 | 先看题目，正确就点解析。改字和原图在题目下，空白作答区默认折叠。已有作答、老师答案或待认领的手写内容时自动展开 | 同样使用居中的单栏题面；展开补充区后并排核对孩子作答与老师答案 |
| 讲解与复习 | 原题在前，按需看一条提示、逐步展开。再次复习时先露出原题 | 左侧保留原题与已有原作答，右侧显示提示、步骤与下一步操作 |
| 独立重做与对照 | 独立写完或确认纸上已做，随后再自评 | 重做时左题右答；对照时左侧显示本次作答，右侧显示参考解法 |
| 收录与订正结果 | 收录反馈随列表或同页圈题出现；订正自评后显示记录和下一步 | 已完成环节与结果并排，题目归属及下一步操作保持可见 |

文字、按钮和圈题手柄采用实色，保留明显的键盘焦点。开场、收录、订正和再练均有静帧替代。
