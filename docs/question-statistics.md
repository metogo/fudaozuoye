# 全站解题次数

统计口径是「新题进入对话页」，不是模型完成解答。首页按产品要求展示「已累计解题 N 次」，N = 初始展示基数 + 实际新增次数。10,000 是配置基数，不能作为已核实的历史解题量使用。

## 数据与权限

- CloudBase 环境：`mini-0324-100046523669-03b06729f`。
- `learning_statistics/question_entries`：`baseline: 10000`、`actualCount: 0`、`metric: conversation_entry`、`version: 1`。
- `learning_submissions`：哈希后的提交标识、所属计数器、服务端入库时间；不保存题干、图片或学生资料。
- 两个集合均为 ADMINONLY，浏览器只访问项目服务端接口。
- 一次事务同时保存去重标识与增加真实次数。读到损坏数据、鉴权错误或更新失败时回滚，不能初始化为假成功数字。

## 运行配置

HTTP 云函数不会自动获得数据库管理身份。服务端需要 `CLOUDBASE_ENV_ID` 与 `CLOUDBASE_APIKEY`。CloudBase 的服务端 API Key 使用环境管理员身份，不能宣称该密钥仅有两个集合的权限；代码只操作两个统计集合不等于云端权限隔离。接入前须明确批准这一权限范围，不能使用客户端 Publishable Key 或放开集合权限代替。

本地把这两个配置写入 Git 忽略的 `.env.local`，保留已有模型配置；开发服务检测到有效配置变化后会自动重载。`.env.example` 只提供空配置项，不含真实凭据。

凭据不可放入 `NEXT_PUBLIC_*`、源码、测试、终端输出或提交记录。不得为接入统计覆盖现有函数配置或模型密钥。配置后须通过真实 SDK 验证普通读取与事务读写。CLI 控制台可操作数据库不代表 SDK 已鉴权。

本地开发建议使用独立测试环境或专用测试计数器，不能把自动化测试写入生产 `question_entries`。当前未配置凭据时接口返回 503，首页提示统计暂不可用，解题不受影响。

## 接口与重试

- `GET /api/learning/statistics`：仅返回 `{total}`，不返回提交明细。
- `POST /api/learning/statistics`：仅接受 `{submissionId: UUIDv4}`，要求合法来源、有效同意凭据并限制请求频率。
- 新题进入对话时创建 UUID 并写入本标签页的待报队列。服务端确认后才移除；网络中断、响应丢失和刷新后重试沿用同一 UUID。
- 识别重试、补图、普通追问、看完整讲解和重做原题不增加次数；点击开始新题并实际提交才增加。
- 队列不依赖同意 cookie 的值生成 ID，cookie 更新不会重复计数。默认 4 秒开始退避、最大 60 秒，恢复网络或聚焦页面会重试。

## 验证与限制

单测覆盖事务回滚、同题并发去重、重建服务实例、凭据轮换后重试、请求校验、异常读取、队列恢复以及中英显示。

本地配置后运行 `npm run verify:statistics:local`，通过真实 SDK 验证读取、新题加一、并发首次提交去重、实例重建及事务回滚。每次只写唯一 `verify_` 前缀计数器，保留带 `verificationOnly` 标记的验证数据供回查，不自动删除或改写正式计数。脚本不会输出凭据；失败时返回非零退出码。

当前固定 SDK 3.8.2 的实测协议：普通读取是 `data: [...]`，事务读取是 `data: { list: [...] }`；事务读取不存在文档会抛出 `code: DOCUMENT_NOT_FOUND`。只允许在检查去重记录时将这个明确错误视为“未提交”，鉴权失败、网络错误和未知结构必须失败并回滚。模拟测试必须复刻实测协议，不能用凭空假定的对象/null 结构替代真实验收。

发布脚本在前端发布前只读校验线上统计接口，未接通数据库时阻止前端发布，不发送测试题污染生产数字。首次接通仍需在独立测试计数器验证真实事务写入。

这是匿名业务统计，不是审计级防刷系统。同意 cookie 和当前进程限流不能证明真实用户身份；多实例防刷需要后续独立设计。浏览器禁用/清空存储或关闭标签页之前尚未成功上报时可能漏计，不能宣称百分百无损。统计不可用不得锁住学习输入。
