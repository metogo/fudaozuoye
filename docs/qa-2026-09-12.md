# 产品回归与性能验收 · 2026-09-12

## 结论与边界

本轮修复已完成本地自动化回归，未提交、推送或部署。现有未提交改动被保留。
这份验收区分功能可靠性和模型内容准确性：接口成功、公式能渲染，不代表知识表述或答案必然正确。
没有生产压测、真机全机型验证，也没有足够样本支持“全部题零失败”或可用率承诺。

## 修复的用户影响

- 重新识别原图时，取消裁剪不再提前清空对话和学习进度；确认新图后才替换。旧预览失效时读取已保存原图，读取失败局部提示，不伪造恢复成功。
- 流式返回支持跨数据块的换行、中文和多行数据。处理失败释放连接；收到完成事件立即结束，不再等待服务器断开才恢复操作。
- 知识卡缓存仅在当前节点和相关连线信息变化时失效。其他节点继续生成，不会导致已看过的卡片再次等待模型；换题不复用旧题内容。
- 知识说明的摘要、应用和缓存统一校验公式完整性；无法恢复的信息不猜写成正确公式。
- 练习公式格式先校验，再独立复核答案。候选和复核共用一次格式纠正额度、40 秒总预算；网络错误、答案不一致不自动反复生成。换题失败保留旧题及作答。
- 对真实英语样例发现的术语误用和规则过度泛化补充约束，并再次运行真实模型核对。提示约束是质量改进，不是确定性正确性保证。

## 真实模型核验与性能

三道合成题通过本地 live API 完成：文字识别 → 首轮讲解 → 图谱 → 根知识卡 → 完整讲解。
未调用统计入口，不使用用户照片。初次测试的一次连接中断来自本地重新编译触发服务重启；稳定服务后重跑三条均完成。

| 样例 | 提交到正文出现 | 图谱请求到根节点 | 知识卡请求到摘要 |
| --- | ---: | ---: | ---: |
| 修路工程题 | 5.48 秒 | 1.86 秒 | 2.70 秒 |
| 欧姆定律 | 4.29 秒 | 1.33 秒 | 2.43 秒 |
| 英语主谓一致 | 3.69 秒 | 2.16 秒 | 2.62 秒 |

这只是单次观测，不是平均值、P95 或优化前后的严格对照。三个流程的完整首轮返回约 11–13 秒；摘要早于完整说明，根节点早于全图。
人工核对数学结果为甲 35、乙 25 米/天，物理为 20 欧姆，英语为 goes。
英语初轮答案正确，但图谱将 every day 误叫频度副词，提醒把 -es 泛化。修正约束后复测：图谱改为时间状语，提醒不再泛化 -es；正文 3.55 秒、根节点 1.57 秒、卡片摘要 3.12 秒。保留原失败记录，不用复测成功覆盖问题事实。

### 练习质量仍有风险

最后一轮四次真实练习请求，三次可用、一次被拒绝：独立复核把 `2 ÷ 0.1` 错算成 `2`，与候选答案不一致，被现有检查拦住，没有展示错误练习。
已加入该真实错误的回归测试。更早一轮曾有两次格式失败，诊断重跑也曾四次全通过；这些波动说明不能据此计算可靠可用率。
两次模型答案一致也不等于数学证明，因此不能宣称每题练习都高准确率。未降低拒绝标准、未将失败伪装为成功，也未通过反复重试刷通过率。

## 无功能降级的性能优化

| 首页生产资源 | 修改前 | 修改后 |
| --- | ---: | ---: |
| JS 总量 | 807,657 B | 798,970 B |
| JS gzip 估算 | 250,839 B | 246,977 B |
| CSS 总量 | 158,942 B | 141,377 B |

保持原预算 800,000 / 250,000 / 150,000 B，不放宽门禁。
按需加载步骤练习、复制模块和白板样式；实际复制按钮出现前模块已经就绪，避免点击后才加载而丢失浏览器剪贴板授权。
没有换低质量模型、压缩教学内容、降低复核要求。JS 改善幅度有限，不宣称首页快一倍；CSS 约减少 11%。
模型等待优化主要是减少重复知识卡请求、复用有效缓存、明确完成立即收尾；不能把资源体积减少直接等同于模型提速。
