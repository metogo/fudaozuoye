## 口径与隐私

基础流量应在已接入的 [ESA 流量分析](https://esa.console.aliyun.com/site/179645347559632/trafficAnalysis) 查看，不以百度同意样本推算全站流量。ESA 在边缘节点统计经过它的请求，不依赖访客点击本站的百度统计设置；本次未新增采集脚本、付费服务或日志导出。

- ESA 页面浏览量：成功 HTML 响应数，不等于全部请求数，也不包含前端 SPA 内部切换。机器人、验收访问、浏览器缓存等会影响口径。
- ESA 的地区、设备、来源等分布以请求为基础，不能当作人数分布；当前控制台未提供已验证的浏览器去重 UV，不能用独立 IP 数冒充真实访客数。
- 百度：用于已同意访客的浏览器 UV 估算及首页、对话、图谱内部访问轨迹。两个来源的 PV 不可直接相加。

- UV 是浏览器/Cookie 识别的访客估计，不是精确人数。未同意、广告拦截、网络失败会导致少计；不能当全量流量。

## 验收

新版弹窗以「一起让小逗号更好用」说明统计用途，首屏直接披露百度采集范围、不发送学习正文及未满 14 周岁的监护人提示；更多统计规则和政策链接可展开。同意使用品牌绿色按钮，拒绝仍可直接点击。仅调整阅读层级，不改变主动同意后才加载的逻辑；不声称已验证同意率提升。设置内状态文案不作为全局实时播报，避免干扰读题反馈。

本地重复验收：开发模式首页底部提供“重置本地统计选择”，只移除 `visitor-analytics-consent-v1`，立即停止当前统计许可并进入真实的未选择状态。同意、拒绝、Esc 和下次访问均走正式逻辑，没有预览分支；不删除题目、会话或其他存储。入口仅限 development + localhost/127.0.0.1/[::1]，生产构建和正式域名不显示。重置失败明确报错，不伪装成成功。本地仍不向百度发送测试数据。

`tests/visitor-analytics.test.tsx` 覆盖域名门禁、未同意、来源脱敏、SPA 去重、撤回及加载竞态、空脚本、失败与超时重试、存储不可用和 StrictMode。

正式验收需要在允许百度统计的浏览器中同意统计，确认官方 `hm.js` 与页面访问请求成功，并在百度统计后台观察数据。`ERR_BLOCKED_BY_CLIENT` 表示浏览器侧拦截，不能报告统计已生效，不能绕过用户的拦截设置。

不能用后台“代码检测成功”、单个 HTTP 200 或本地 Mock 代替真实入库验证。百度后台展示有处理延迟。
